# Cycle 33 — second render-class sweep: 15 survivors of the first one

## Why a second sweep

Note 20260527210320-3898 recorded the cycle-27 sweep and asserted: "Zero such reasons remain in
the catalog." Enumeration found **15 form×channel cautionaries still resting on the prose-slot
premise** — the exact phrasing that note established as the signature of a mis-layered composition.

**The false claim is what let these survive unexamined for six cycles.**

## Routing test

The narrowed axis rule supplies the test: **does the channel have a construct that can carry this
form?** Where yes, the cautionary is simply wrong (retire). Where no, the content still coexists
(adjacent-block composition). Each decision below names the construct or its absence.

Each new entry names the specific reason the channel cannot carry the form (e.g. "a CodeTour step is

### Retained — correctly reasoned, not render-class (1)

its key." This is a vocabulary-closure reason, not a rendering one, so the adjacent-block resolution
does not apply — an adjacent key would not make the Gherkin body use the notation.
